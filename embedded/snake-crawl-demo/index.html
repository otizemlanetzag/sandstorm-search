About Snake Crawl

Snake Crawl is an open-source web crawler for discovering and collecting web pages, links, metadata, and readable content. It includes a normal seed-based crawler and an advanced discovery mode, with crawl results that can be saved to DATA.CSV.

View Snake Crawl on GitHub

Control Panel

Enter the secret code to open the crawler. The code protects the crawler control panel so unauthorized visitors cannot start crawls or trigger requests through the service. for this demo, enter 1234

Advanced Discovery

Generates a bounded batch of domain candidates, tests them, and records reachable results. This mode is separate from the seed-based crawler.
